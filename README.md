Supermart Grocery Sales Dashboard

An interactive sales analytics dashboard built to explore grocery retail performance across sales, profit, product categories, discounts, and geography.

Project Overview

This project analyzes the Supermart Grocery Sales dataset to identify sales trends, evaluate profitability, compare product categories, and explore regional performance.

Features

Interactive Filters: Filter results by year, category, and region.

Sales Performance: Explore monthly sales and profit trends.

Product Analysis: Compare sales and profitability across sub-categories.

Discount Analysis: Examine the relationship between discounts and profit.

Geographic Analysis: Compare performance across cities and regions.

Responsive Design: Dashboard layout adapts to different screen sizes.

Dark Mode: Toggle between light and dark themes.

Tools & Technologies

CSS

Dataset

Supermart Grocery Sales – Retail Analytics Dataset, covering 2015–2018.
